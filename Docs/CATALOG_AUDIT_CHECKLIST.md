# Audit catalog `foods` (calitate recomandări)

Motorul nu poate depăși calitatea datelor. Înainte de demo final / producție:

- [ ] Fiecare categorie are suficiente intrări (carne, pește, leguminoase, lactate, cereale, fructe, legume).
- [ ] Valorile nutriționale per 100g sunt plausibile (fier, B12, D, calciu, etc.).
- [ ] Câmpul `allergens` este completat unde e relevant (pentru filtrare).
- [ ] Denumiri consistente (fără duplicate aproape identice cu valori diferite).
- [ ] Produse „mese” / procesate marcate corect în categorie (impact la reguli și OpenFoodFacts).
- [ ] Import CSV verificat pe un eșantion (5–10 rânduri) comparativ cu sursa.

Schema tabelelor este descrisă în README-ul principal al proiectului.
